# 강릉 교통정보 모음 (gangneung-its-archive)

강릉시 교통정보를 10분마다 한 장씩 찍어 쌓아 두는 저장소입니다. GitHub Actions가 자동으로 돌립니다.

- **자료 출처**: 공공데이터포털 「강원특별자치도 강릉시_교통정보 조회서비스」 (강릉시 ITS추진과)
- **가져오는 곳**: [강릉 3D 지도](https://gangneung-map.vercel.app)의 서버 함수 `/api/gn-its`
- **모으는 것**: 공영주차장 주차 대수, 스마트교차로 서비스수준·지체시간, 회전교차로 교통량·속도, 스마트횡단보도 통행(오늘 누적), 돌발 감지

## 파일

| 경로 | 내용 |
|---|---|
| `data/YYYY/MM/DD/HHMM.json` | 한 시각의 자료 (한국 시각, 강릉시 자료 기준 시각) |
| `data/parking_info.json` | 주차장 이름·주소·좌표·운영시간·전체 면수 |
| `data/latest.txt` | 마지막으로 저장한 기준 시각 |

각 파일의 항목 순서는 `scripts/collect.py` 안의 설명을 보세요.

## 알아 둘 점

- 주차장의 '주차한 차 수'가 0이면 실시간 자료가 없는 곳인 경우가 많습니다.
- GitHub 예약 실행은 몇 분씩 밀리거나 가끔 건너뜁니다. 빈 시각이 있을 수 있습니다.
- 스마트교차로는 방향별 자료를 교차로 하나로 묶었습니다 (가장 나쁜 서비스수준, 가장 긴 지체, 교통량 합).
